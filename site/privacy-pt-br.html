Regula / Privacidade

Privacidade e análises

O que este site coleta e o que não coleta, dito com clareza. Última atualização: 14 de agosto de 2026. Esta página descreve a prática atual e será atualizada se a prática mudar.

A versão curta

Este site não tem contas, formulários de cadastro nem newsletter, e não define cookies próprios. A avaliação no navegador roda no seu dispositivo e não envia suas respostas para nós. As análises são sem cookies e por eventos, sem identificadores pessoais. Uma coisa a saber antes de usar o recurso de compartilhamento: o link compartilhado contém suas respostas codificadas; compartilhe apenas com quem deve vê-las.

Quem opera este site

Regula é um projeto de código aberto mantido por Kuziva Muzondo (veja a página Sobre). Para qualquer dúvida ou solicitação sobre esta página, escreva para support@getregula.com.

O que este site coleta diretamente

Nada. Não há login, nenhum formulário que envie dados para nós e, no momento, nenhum fluxo de pagamento ou reserva neste site. Links de e-mail no site abrem o seu próprio aplicativo de e-mail; nada é enviado pelo próprio site.

Análises

Usamos o Plausible Analytics, carregado de plausible.io. É um serviço de análises sem cookies: não define cookies e não faz rastreamento entre sites. Vemos contagens agregadas de visualizações de página e de eventos nomeados, como iniciar ou concluir uma avaliação, copiar um comando, exportar um resultado, abrir uma pergunta na página de preços ou clicar em um link de contato por e-mail. Os rótulos dos eventos se limitam a coisas como a jurisdição escolhida ou o plano ao qual um botão pertence; nunca incluem nomes, e-mails ou identificadores de conta, porque nada disso existe neste site. Como o Plausible trata as requisições subjacentes está descrito na política de dados do Plausible.

A avaliação no navegador

A avaliação roda inteiramente no seu navegador. Suas respostas são processadas no seu dispositivo e não são enviadas para nós. A exportação em JSON é um download local. Se você usar o recurso de compartilhamento, suas respostas são codificadas no próprio link: qualquer pessoa com o link pode decodificá-las, e qualquer serviço que manipule o link, inclusive o servidor que hospeda este site quando o link é aberto, pode ver a sequência codificada. Ao abrir um link compartilhado, a página remove as respostas codificadas da barra de endereço antes de o script de análises carregar; elas não entram, portanto, nas nossas análises.

Hospedagem

Este site é servido pelo GitHub Pages. O GitHub pode registrar endereços IP de visitantes em seus logs ao servir qualquer site do GitHub Pages, como descrito na documentação do GitHub Pages e na declaração geral de privacidade do GitHub. Nós não recebemos esses logs.

A CLI e os pacotes

A ferramenta de linha de comando Regula roda localmente e não envia o conteúdo dos arquivos analisados. O relatório opcional de falhas só funciona com consentimento explícito, pergunta antes de enviar qualquer coisa e pode ser totalmente suprimido com a variável de ambiente REGULA_NO_TELEMETRY. A implementação é de código aberto e pode ser lida no repositório.

E-mail

Se você escrever para support@getregula.com, usamos sua mensagem apenas para responder. Você não é adicionado a nenhuma lista.

Suas dúvidas e direitos

Dependendo de onde você mora, a legislação de proteção de dados pode lhe dar direitos em relação ao tratamento feito pelos serviços citados acima; as políticas vinculadas descrevem como exercê-los junto a esses provedores. Para qualquer assunto envolvendo este site ou projeto, contate support@getregula.com e responderemos.

Alterações

Alterações nesta página são publicadas aqui com a data atualizada. O histórico da página é público no repositório.

Provenance. The terminal output uses regula check examples/cv-screening-app --scope all. Generate the linked documents with regula report examples/cv-screening-app --domain employment --scope all --format html -o report.html, then repeat with --format exec-summary -o summary.html. The local working tree includes unreleased changes; the version label alone does not identify those changes. Source installed from @main can differ. Display adjustments replace machine-specific paths with /home/USER and add noindex to the linked documents. The original files and command evidence were retained for review.

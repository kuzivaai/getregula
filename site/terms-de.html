Nutzungshinweise

Hinweise zur Nutzung dieser Website, klar gesagt. Zuletzt aktualisiert am 14. August 2026.

Was diese Website ist

getregula.com ist die Website von Regula, einem Open-Source-Werkzeug, das Code auf Muster untersucht, die eine KI-Governance-Prüfung erfordern könnten, und Einsatzfakten erfasst, die der Code nicht zeigen kann. Die Website bietet Informationen, Guides, eine Browser-Bewertung und Links zur Software. Sie wird vom Betreuer des Projekts betrieben (siehe die About-Seite).

Keine Rechtsberatung

Nichts auf dieser Website ist Rechtsberatung, eine Compliance-Feststellung, eine Zertifizierung oder eine Konformitätsbewertung. Inhalte und Werkzeugausgaben zeigen an, was einer Prüfung bedürfen könnte; ob ein Gesetz auf ein reales System anwendbar ist und was es verlangt, sind Fragen für qualifizierte Fachleute mit Kenntnis Ihrer Umstände. Wo eine Seite ein regulatorisches Datum oder eine Vorschrift nennt, geben wir die Quelle an; Regulierung kann sich nach Veröffentlichung einer Seite ändern.

Derzeit werden über diese Website keine kostenpflichtigen Leistungen angeboten

Die Preisseite beschreibt eine geplante Beratungsleistung. Diese Beschreibung ist kein Verkaufsangebot: Über diese Website kann derzeit weder gezahlt noch gebucht werden, und die Seite sagt das ausdrücklich. Sollte sich das ändern, werden Leistung, Anbieter, Preis und Bedingungen veröffentlicht, bevor etwas gekauft werden kann.

Software-Lizenzen

Die Regula-Software ist quelloffen: Code unter Apache-2.0 / EUPL-1.2, Erkennungsregeln unter DRL 1.1, wie in der NOTICE-Datei des Repositorys beschrieben. Die Software wird gemäß diesen Lizenzen ohne Gewährleistungen oder Bedingungen jeglicher Art bereitgestellt. Für Ihre Nutzung der Software gelten die Lizenzen, nicht diese Seite.

Website-Inhalte

Die Texte dieser Website werden sorgfältig erstellt und ihre Tatsachenaussagen gegen benannte Quellen geprüft; sie werden jedoch ohne Gewähr für Vollständigkeit oder Aktualität bereitgestellt. Fehler melden Sie bitte an support@getregula.com oder als Issue im Repository; die vollständige Historie der Website ist dort öffentlich.

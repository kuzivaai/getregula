# Understanding findings

Each finding maps to an EU AI Act risk tier:

| Severity | Tier | Meaning |
|----------|------|---------|
| Error | Prohibited (Article 5) | Banned AI practices |
| Warning | High-risk (Annex III) | Requires conformity assessment |
| Info | Limited-risk (Article 50) | Transparency obligations |
| Hint | Minimal-risk | No mandatory requirements |

Click any finding's diagnostic code to see the rule documentation on getregula.com.

Use Quick Fix to suppress or accept findings:
- **regula-ignore** — suppress the finding
- **regula-accept** — accept the risk with an owner and review date

# Install the Regula CLI

Regula VS Code runs the Regula CLI under the hood. Install it with:

```bash
pipx install git+https://github.com/kuzivaai/getregula.git@main
```

Or with pip:

```bash
pip install git+https://github.com/kuzivaai/getregula.git@main
```

Verify the installation:

```bash
regula --version
```

# Run your first scan

Open any Python, JavaScript, TypeScript, Java, Go, Rust, C, or C++ file and save it. Regula scans automatically on save.

You can also trigger a scan manually:

1. Open the Command Palette (`Ctrl+Shift+P` / `Cmd+Shift+P`)
2. Type **Regula: Scan Current File**
3. Press Enter

Findings appear in the **Problems** panel and as inline diagnostics.

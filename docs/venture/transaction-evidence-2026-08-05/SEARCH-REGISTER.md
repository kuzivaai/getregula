## Auditability limitations

Retrieval used the public web search/open interface. It returned canonical URLs
and indexed excerpts but not stable response files suitable for hashing; content
hashes were not captured. Filters beyond exact query strings were unavailable.
Early-round unresolved-gap rankings were described during the session but not
durably recorded after every round. The 17 retained rows map unique inclusions;
non-retained results are grouped by exclusion category rather than individually
URL-listed. These protocol deviations limit reproducibility and source-selection
review. The record is not described as evidence-complete or exhaustive.

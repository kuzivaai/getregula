# Data-reuse permission draft

STATUS: PREPARATION ONLY
EXTERNAL ACTION: DISABLED
VENTURE DECISION: STOP
PRODUCT PILOT: NOT APPROVED

LEGAL REVIEW: REQUIRED. REAL DATA COLLECTION: DISABLED.

Initial participation does not authorise reuse. Specify exact source data,
derived data, new purpose, recipients, identifiability, commercial/public use,
duration, withdrawal boundary, security, transfers and attribution. Choices are
granular and default to no reuse. Pseudonymised data remains personal data where
re-identification is reasonably possible.

# Data-rights request procedure template

STATUS: PREPARATION ONLY

VENTURE DECISION: STOP
PRODUCT PILOT: NOT APPROVED

LEGAL REVIEW: REQUIRED

REAL DATA COLLECTION: DISABLED

This draft is not legally approved. It distinguishes a UK GDPR rights request
from voluntary research withdrawal. Before use, record controller authority,
request date and scope, proportionate identity check, systems and processors to
search, statutory response deadline, any extension or refusal basis requiring
advice, disclosures made, action taken, requester response and closure date.
Search scope must include contact records, recordings, transcripts, token maps,
annotations, exports, logs, caches and backups. Do not promise erasure where an
exception may apply; refer the decision to the authorised controller or adviser.

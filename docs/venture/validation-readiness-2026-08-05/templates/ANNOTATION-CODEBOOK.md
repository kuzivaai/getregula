# Annotation codebook

STATUS: PREPARATION ONLY
EXTERNAL ACTION: DISABLED
VENTURE DECISION: STOP
PRODUCT PILOT: NOT APPROVED

Protocol: PREREGISTERED_NOT_EXECUTED. REAL DATA COLLECTION: DISABLED.

Unit: frozen buyer-requirement × repository-evidence decision. Labels:
`PRESENT_SUPPORTED`, `PRESENT_CONTRADICTORY`, `NOT_FOUND_IN_FROZEN_REVIEW_SCOPE`,
`NOT_ASSESSABLE`, `ABSTAIN`, `OUT_OF_SCOPE`. Each record requires unit ID,
repository/transaction cluster, rater pseudonym, label, exact evidence pointer,
rationale, confidence, time and codebook version. `NOT_FOUND_IN_FROZEN_REVIEW_SCOPE` requires
documented search scope; ambiguity is never silently forced positive or negative.

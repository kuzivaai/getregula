# Protocol deviations

STATUS: OPEN RECORD

1. The requested date-only directory already contained a completed and committed
   protocol. A timestamped successor directory was used to avoid rewriting a
   protocol after its conclusions were known.
2. PRISMA-S and PRESS were developed for systematic evidence syntheses. They are
   used selectively for search reporting and query review; this review is not
   represented as a systematic review.
3. The prior review lacked stable raw web-response files and content hashes for
   many sources. The successor review records this limitation rather than
   reconstructing those artefacts.

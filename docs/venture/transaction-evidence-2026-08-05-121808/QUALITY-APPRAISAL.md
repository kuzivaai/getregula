# Quality appraisal

STATUS: PREREGISTERED BEFORE SUCCESSOR SEARCH

Each included source is assessed for directness, independence, attributable
organisation, publication/event dates, role and geography match, reproducibility,
contrary evidence and decision consequence. Primary buyer or transaction records
outrank vendor and user accounts for buyer-workflow claims. Multiple pages that
repeat one origin count once. A source can support context while remaining
insufficient for H1.

Strong H1 support requires transaction-linked evidence. Regulation, use-case
existence and vendor capability alone cannot cross the public-evidence gate.
